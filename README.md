### 🧠 Architectural Philosophy
- **Push compute down:** If the database engine can process it natively, don't drag millions of rows across a network to do it in an app container.
- **Design for failure:** Assume source schemas will drift, nulls will sneak in, and networks will drop. Build pipelines that recover automatically.
- **Performance is a design choice:** Tuning starts with index design and execution plans, not when a pipeline times out in production.
